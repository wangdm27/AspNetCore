```
AspNetCore.Api
  └── AspNetCore.DataAccess

AspNetCore.Test3
  └── AspNetCore.RabbitMq
```

- `Test3` 是唯一消费 `AspNetCore.RabbitMq` 库的项目。

## 4. 各模块一句话职责

- **DataAccess**：通过单一入口 `AddUnifiedDataAccess<TDbContext>` 按配置切换 EF Core 或 Dapper，统一 `IRepository<T>` / `IUnitOfWork` 抽象，支持 SqlServer / PostgreSQL。
- **RabbitMq**：封装连接（双重检查锁 + 自动恢复）、通道池（信号量 + 并发队列）、发布者、消费者基类、Outbox（内存存储 + 后台调度器）。
- **Redis**：封装 `ConnectionMultiplexer`，提供键前缀、JSON 序列化、`SetNx`/`Lock` 等分布式锁原语。
- **Api**：多租户 + RBAC 权限的 Web API。模块化组织（Identity / Authorization / Tenancy），JWT 认证、基于权限码的授权过滤器、审计日志、SMTP 邮件、数据库初始化种子。

## 5. API 启动流程

入口：`AspNetCore.Api/Program.cs`

```
CreateBuilder
  ├─ AddControllers + AddOpenApi
  ├─ AddUnifiedDataAccess<ApplicationDbContext>(Configuration)   # 数据访问，按 Database:Orm 切换 EF/Dapper
  ├─ AddAuthorization
  ├─ AddBusinessModules(Configuration)                          # 业务服务 + JWT + 邮件 + 审计 + DB 初始化 HostedService
  └─ AddCors("AllowAll")
Build
  ├─ (Dev) MapOpenApi
  ├─ UseMiddleware<ApiExceptionMiddleware>                     # 统一异常 → 400/500 JSON
  ├─ UseHttpsRedirection
  ├─ UseCors("AllowAll")
  ├─ UseAuthentication → UseAuthorization
  └─ MapControllers
```

关键服务注册见：
- 数据访问：`AspNetCore.DataAccess/ServiceCollectionExtensions.cs:23`
- 业务模块与 JWT：`AspNetCore.Api/Infrastructure/Extensions/ServiceCollectionExtensions.cs:15`
- 数据库初始化（`EnsureCreatedAsync` + 权限/菜单种子）：`AspNetCore.Api/Infrastructure/DatabaseInitializationHostedService.cs:16`

## 6. 关键配置（`appsettings.json`）

| 节 | 说明 |
| --- | --- |
| `Database` | `Provider`(SqlServer/PostgreSql)、`Orm`(EntityFrameworkCore/Dapper)、`ConnectionStringName`、`CommandTimeoutSeconds` |
| `ConnectionStrings` | `SqlServer`、`PostgreSql` 连接串 |
| `Jwt` | `Issuer`/`Audience`/`SigningKey`/`AccessTokenExpiresMinutes`(120)/`RefreshTokenExpiresDays`(7) |
| `Email` | SMTP 参数 + `PasswordResetUrl`（`{token}` 占位） |

> 生产约束：JWT `SigningKey` 不得使用默认值，否则启动抛 `InvalidOperationException`（`ServiceCollectionExtensions.cs:39`）。优先读环境变量 `JWT_SIGNING_KEY`。

## 7. 数据模型概览

`ApplicationDbContext`（`AspNetCore.DataAccess/ApplicationDbContext.cs`）定义 11 个 DbSet：

```
Tenants ──< TenantUsers >── Users
Tenants ──< Roles ──< RolePermissions >── Permissions
                 Roles ──< UserRoles >── Users
Menus (自引用树)
RefreshTokens >── Users
AuditLogs
SampleEntities
```

实体配置（表名 / 列名 / 索引 / 外键级联）集中在 `ApplicationDbContext.OnModelCreating`。
权限类型枚举 `PermissionType`：`Api / Menu / Button`（`Entities/Enums/PermissionType.cs`）。

详见 [01-DataAccess-数据访问层.md](./01-DataAccess-数据访问层.md)。
